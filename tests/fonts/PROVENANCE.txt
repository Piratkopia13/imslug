Test fonts — provenance
=======================

Both fonts are committed unmodified, only as test assets for the glyph
pipeline (outline extraction, band generation, CPU reference rasterizer and
ImGui metric parity tests). Each font keeps its license text next to it.

Notes
-----
* No reserved-font-name renaming applies: the files are byte-identical to the
  upstream releases (no subsetting, no modification), so the OFL/Apache
  conditions for derived versions do not apply.
* Roboto is the primary test font; Inter is the second, to catch glyph-data
  assumptions that only hold for one font (composites, curve counts, extents).
